# الاستبيانات الذكية

تطبيق ويب عربي لإدارة الاستبيانات والأسماء وحملات التوزيع، مع محاكاة نتائج ببيانات اصطناعية موسومة، وتقارير PDF بمقاس A4 وتصدير CSV وExcel.

React · TypeScript · Tailwind · Vite · Supabase (اختياري)

## النشر على GitHub Pages (دون أوامر)

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع محتويات هذا المجلد إلى فرع `main` (زر **Add file ← Upload files**، واسحب كل الملفات والمجلدات بما فيها `.github`).
3. من **Settings ← Pages** اختر **Source: GitHub Actions**.
4. انتظر دقيقتين حتى ينتهي تبويب **Actions**، ثم افتح الرابط:
   `https://اسم-المستخدم.github.io/اسم-المستودع/`
5. اضغط «تثبيت التطبيق» من القائمة الجانبية لتثبيته على الجهاز.

كل تعديل تدفعه إلى `main` يُنشر تلقائيًا.

## التشغيل محليًا

```bash
npm install
npm run dev      # خادم تطوير
npm run build    # نسخة الإنتاج في dist/
```

## Supabase (اختياري)

- شغّل `supabase/schema.sql` في SQL Editor بمشروعك.
- أدخل رابط المشروع والمفتاح العام من صفحة «التخزين والإعدادات»، أو انسخ `.env.example` إلى `.env` واملأه.
- لا تضع مفتاح `service_role` في الواجهة أبدًا.

دون Supabase تُحفظ البيانات في متصفح المستخدم فقط.

## مبادئ التطبيق

- الردود الاصطناعية موسومة دائمًا، ولا تُدمج مع الحقيقية، ولا تُرسل لأي منصة خارجية.
- لا يُنشأ رد باسم شخص حقيقي؛ قائمة الأسماء للدعوات ومتابعة من أجاب فقط.
- لا تجاوز لتسجيل الدخول أو CAPTCHA، ولا إرسال تلقائي إلى نماذج طرف ثالث.

## البنية

```
src/
  pages/        الصفحات (لوحة التحكم، الاستبيانات، الحملات، المحاكاة، التقارير…)
  components/   مكونات الواجهة والرسوم
  lib/          البيانات، التوليد الاصطناعي، التحليل، PDF، Supabase، التكاملات
public/         الأيقونات وملف manifest وخدمة العمل دون اتصال
supabase/       مخطط قاعدة البيانات وسياسات RLS
```
